# AI-Enabled Employee Management System

An AI Enabled Management System with analytics dashboard built using Java Spring Boot & MySQL.

This project manages employee data efficiently and provides insightful analytics for HR management.

### ✨ Features
- Add, Update, Delete, and View Employees (CRUD Operations)
- Search and Filter by Department
- Pre-loaded with 6 Sample Employee Records
- MySQL Database Integration
- Built with Spring Boot

### 🛠️ Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- IntelliJ IDEA

### 🚀 How to Run
1. Clone the repo: `git clone https://github.com/VarshaBhatnagar964/AI-Employee-Management-System.git`
2. Create MySQL database `employee_db`
3. Update `application.properties` with your DB username & password
4. Run `EmployeeManagementApplication.java`
